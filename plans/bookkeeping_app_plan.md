# 写真から帳簿作成Webアプリ：開発計画書

## 0. 背景
「DX」の最大の障壁は、現場の慣習を壊してしまうこと。本アプリは以下の考えに基づく：
- **「出口だけデジタル」**：入力（書く）は紙のまま、出口（管理）だけをデジタル化
- 写真を撮ってスプレッドシートに保存するだけのシンプル構成
- 将来的な電子帳簿保存法対応 подготовка

## 1. コンセプト
**シンプルで誰にでも使える**：高齢者やWebリテラシーの低い方も使いやすく

## 2. 概要
領収書・請求書・紙の帳簿の写真を撮って、Googleスプレッドシートにテキストと画像の両方を保存するWebアプリ。

## 3. 技術スタック
- Next.js (App Router) + TypeScript + Tailwind CSS
- Google Sheets API（データ保存）
- Vercel（ホスティング）

## 4. 設計方針
- 画面は1つだけ（撮影 → 内容入力 → 保存）
- 大きなボタン、明確な文字
- 操作は3ステップ以内
- 操作に迷わないようガイダンス表示

## 5. ユーザーUXフロー
